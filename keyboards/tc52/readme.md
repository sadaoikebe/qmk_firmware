# TC52 (TS52K capacitive / EC)

52-key NICOLA (oyayubi shift) keyboard, capacitive (Topre-style EC) version of TS52K,
on-board RP2040. Sensing code ported unchanged from the rebuilt TC69 firmware
(`keyboards/tc69`); pins and matrix from `ts52k-ec/design-spec.md`; logical layout and
keymaps from TS52K. Details: `ts52k-ec/tc52-firmware.md`. **Not yet tested on hardware.**

    make tc52:nicola                       # normal firmware (NICOLA)
    make tc52:nicola TC52_ADC_DIAG=yes     # + raw ADC dump over QMK console
    make tc52:default                      # plain QWERTY, for matrix bring-up

`keyboard.json` and `tc52_matrix.h` are generated by `firmware-rebuild/tools/gen_tc52.py`
(`./build-tc52.sh --regen`); do not edit them by hand.

Flashing: hold BOOTSEL while plugging in USB, then copy the .uf2 to the RPI-RP2 drive.
Bootmagic is not enabled (as TC69). Do not touch the keys for the first moment after
plug-in: the baseline is calibrated once at start-up.
